The problem

移動中の情報は、まだ体験になっていない。

人は移動中に、目的地、食事、予定変更、天気、混雑、交通手段、地域情報を考えています。しかし情報はアプリ、検索、SNS、地図、レビューに分断されています。

MarsLinkは、情報を増やすのではなく、移動中の文脈に合わせて整理し、次の体験へ接続することを目指します。AIは人の代わりに旅を決めるものではありません。人が安心して選べる状態をつくるものです。

Mission, Vision, Values

MarsLinkは、移動中の意思決定を支える会社です。

CabinTimeは入口です。私たちがつくりたいのは、AIが状況を理解し、人が安心して判断できる状態をつくるための基盤です。

Mission

移動中の判断を、安心できる体験に変える。

検索結果やレビューを増やすのではなく、その人の状況に合う選択肢へ整理する。

Vision

AI時代のDecision Intelligenceへ。

移動という、人が頻繁に判断する場所から、社会の意思決定を支える基盤へ拡張する。

Values

Reality. Clarity. Trust. Velocity.

現場の制約から設計し、複雑さを削ぎ落とし、信頼できるAIを速く検証する。

Product surfaces

CabinTimeとJourney AI。

CabinTimeは、通信制約や専用空間にJourney AIを入れる初期導入パッケージです。Journey AIは、移動と滞在の文脈を理解し、個人に合わせて次の行動を判断できる状態をつくるAI体験です。

CabinTime

閉ざされた移動・滞在空間へ入る初期パッケージ。

Air、Seaを起点に、Rail、Coach、Stay、Regionへ。スマートフォン、機内・船内ポータル、ローカル実行、最新情報連携をまとめて導入し、移動中の判断支援を現場で検証する。

CabinTime architecture

CabinTimeは、Journey AIを移動空間で動かす初期導入パッケージです。
